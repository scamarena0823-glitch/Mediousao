# Seguridad

Si encuentras una vulnerabilidad de seguridad, no publiques credenciales ni secretos en un issue.

Contacta al responsable del repositorio de forma privada para reportarla.

**Nunca compartas en GitHub:**
- contraseñas
- claves `service_role` de Supabase
- tokens privados
- credenciales de base de datos
- archivos `.env` con secretos

La clave pública/publicable usada por una aplicación frontend no sustituye la configuración correcta de RLS y Auth en Supabase.
